# Catalogo de Componentes

## Base UI
- `Button`: variantes (`default`, `outline`, `secondary`, `ghost`, `link`, `destructive`, `success`) e estado `loading`.
- `Input`: suporte a `label`, `hint`, `error`, atributos de acessibilidade.
- `Badge`: variantes semanticas para status.
- `Card`: estrutura composavel de conteudo.

## Shared
- `OrderStatusBadge`: mapeamento de estado de pedido para label/cor.
- `DashboardHeader` e `DashboardSidebar`: navegacao do painel.
